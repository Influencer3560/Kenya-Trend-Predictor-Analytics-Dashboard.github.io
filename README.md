# Kenya-Trend-Predictor-Analytics-Dashboard.github.io
interactive Kenya Social Media Trend Predictor &amp; Analytics Dashboard tailored specifically to Tech &amp; Business and Entertainment &amp; Pop Culture.


Key Highlights of the Application Built:

Category Focus: Specialized filters for Tech & Business (e.g., M-Pesa API, KRA eTIMS, Y-Combinator Kenya) and Entertainment & Pop Culture (Gengetone trends, Kalasha Awards, viral audio).

Heuristic & Frequency Velocity Engine: Visual representation of the exponential time-decay acceleration formula $V(t) = \frac{C_t - C_{t-1}}{\max(1, C_{t-1})} \times e^{-\lambda \Delta t}$, complete with live slider controls to adjust detection sensitivity.

Deep Research Modal Launcher: Click on any trend to launch direct search queries across X (Twitter), Google Trends KE, r/Kenya, and TikTok KE with pre-populated parameters.

Interactive Dashboard Features: Live ticker updates, high-velocity metric KPIs, multi-platform co-occurrence tracking, and a simulated pipeline scan button.

Notification Pipeline Testing: Configurable push/webhook toggles and interactive test triggers for in-browser alerts.


Step-by-Step Architecture: 

How It Works

1. Data Ingestion (Python & Pytrends)What happens: A Python script queries the Google Trends API (pytrends) and public data feeds targeting Kenya (geo='KE').The Focus: It pulls hourly/daily search interest metrics and velocity figures specifically for keywords in Tech & Business (e.g., software, fintech, taxation, startups) and Entertainment & Pop Culture (e.g., local artists, slang, viral shows, entertainment events).

2. The Heuristic Velocity EngineWhat happens: Instead of complex black-box machine learning algorithms that require thousands of labeled historical rows, the script uses a frequency acceleration formula:$$V(t) = \frac{C_t - C_{t-1}}{\max(1, C_{t-1})} \times e^{-\lambda \Delta t}$$The Logic: It measures how fast a topic's mention count or search volume ($C_t$) is growing compared to the previous period ($C_{t-1}$). If the growth rate exceeds your configured sensitivity threshold, it flags the topic as an emerging trend rather than just something that's already popular.

3. Free Cloud Automation (GitHub Actions)What happens: You don't need to keep your computer turned on or pay for a server. We place the Python script inside a GitHub repository and configure a GitHub Actions workflow file (.github/workflows/trend_checker.yml).The Schedule: It uses a cron schedule (e.g., running every morning at your preferred hour) to spin up a free virtual Linux container, run the script, analyze current Kenyan trends, and output a lightweight JSON file containing the top results.

4. Notification & Mobile AlertsWhat happens: When the script detects a high-velocity trend, it triggers a notification payload. This can be delivered directly to your phone via a Telegram Bot API, web push notification, or email alert so you know immediately when something worth researching pops up.

5. Your Web Dashboard InterfaceWhat happens: The front-end webpage (like the interactive dashboard we built) fetches the latest JSON output file generated by your automated pipeline.Your Workflow: You open your dashboard, see the fresh tech, business, and entertainment trends ranked by velocity, and click any card to instantly launch deep-search research tabs on platforms like X, Google Trends KE, and Reddit.


Here is how data science comes into play across our project pipeline:

1. Time-Series Analysis & Temporal MetricsWhat we do: We pull hourly and daily data points from Google Trends (pytrends) and social signals over time.The Data Science link: You are tracking a time-series dataset to spot temporal patterns, seasonality, and sudden behavioral changes in the Kenyan digital space.

2. Statistical Feature Engineering & Velocity ModelingWhat we do: Instead of just looking at what keywords have the highest total mentions (which usually just shows what's already mainstream), our heuristic formula measures acceleration and rate of change:$$V(t) = \frac{C_t - C_{t-1}}{\max(1, C_{t-1})} \times e^{-\lambda \Delta t}$$The Data Science link: This is classic feature engineering. We are transforming raw counts into a derived statistical metric (velocity/momentum) with exponential time-decay to mathematically isolate emerging trends from stagnant ones.

3. Text Analytics & Frequency ExtractionWhat we do: Parsing text data from public discussions, hashtags, and titles across X, Reddit (r/Kenya), and news feeds.The Data Science link: This involves text mining techniques—cleaning strings, tokenizing keywords, tracking co-occurrences, and aggregating term frequencies to find what topics are clustering together.

4. ETL Pipeline & Data Architecture (Extract, Transform, Load)What we do: A Python script automatically fetches raw data (Extract), cleans, filters, and computes velocity scores (Transform), and outputs a structured JSON file that populates your frontend dashboard (Load).The Data Science link: This is the core end-to-end operational pipeline required to take raw, unstructured web data and turn it into an automated decision-support system.
